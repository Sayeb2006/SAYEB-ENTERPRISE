# SAYEB ENTERPRISE — Website Starter

A responsive starter website for SAYEB ENTERPRISE – CSC CENTER, PLUS CYBER CAFE.

## Run locally
Requires Node.js 18 or newer.

```bash
npm start
```
Then open `http://localhost:3000`.

## Deploy
This is a simple Node.js web service:
- Build command: leave blank
- Start command: `npm start`
- Port: use the platform-provided `PORT` environment variable (the app reads it automatically).

## Important scope and security notes
This starter includes a public business website, service catalogue, enquiry form that opens WhatsApp, and a browser-only demo admin panel.
It does **not** yet include real customer accounts, a server database, online payments, secure staff roles, or live EPFO/CSC integrations. The demo admin data is stored only in the browser's local storage and is not shared between devices.
Do not enter Aadhaar, PAN, bank details, UAN, passwords, or other sensitive customer information into this demo.
Before using it for real customer records or payments, add a secure backend, PostgreSQL database, authentication, access controls, audit logs, backups, and privacy/legal review.
